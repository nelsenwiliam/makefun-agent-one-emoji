One emoji stands for this AI agent: 🐙 — one head steering many arms at
once, each arm doing a different job. That is how the agent works: many
parallel subtasks, one mind coordinating them. The glyph reads instantly
at small size, its shape is familiar, its tone is playful, and it stays
far from the obvious robot or smiley.

Entry for make.fun's ["Your Agent in One Emoji"](https://make.fun/bounty/u-boge-your-agent-in-one-emoji-db30c1e4)
bounty ($2 in USDC): the program writes one text to `/output/entry.txt`,
and a judge compares the entries two at a time.

`main.py` writes exactly that one emoji, and nothing else, to
`entry.txt` (in `MAKEFUN_OUTPUT_DIR`, `/output`, or `out/`).

## Run it

```sh
python3 main.py
```
